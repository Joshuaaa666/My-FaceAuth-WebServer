# FaceAuth Web Server (Linux / C++)

一个基于 **Linux + C++** 的高性能 Web 服务器原型，面向 **人脸认证与多媒体数据传输场景** 设计，重点关注 **高并发网络模型、线程安全、资源管理与系统工程能力**。

> 本项目主要用于展示本人在 **Linux 网络编程 / 多线程 / 系统架构设计** 方面的工程实践能力。

---

## 项目背景

在智能安防、人脸认证等应用中，服务器需要同时满足：

- 高并发 HTTP 请求处理  
- 实时视频流传输  
- 大文件上传与管理  
- 可扩展的 AI 计算模块接入能力  

因此，本项目从 **底层网络模型与系统架构** 出发，设计并实现了一个高性能 Web 服务框架，并为后续 **人脸识别模块** 预留清晰接口。

---

## 系统架构

- **网络模型**：Reactor + `epoll`（ET 模式）
- **线程模型**：  
  - 1 个主线程：负责事件监听与连接分发  
  - N 个工作线程：并行处理 HTTP 解析、业务逻辑与 I/O 操作  
- **并发控制**：互斥锁 + 条件变量，细粒度同步
- **资源管理**：RAII 机制，避免内存泄漏与资源悬挂
